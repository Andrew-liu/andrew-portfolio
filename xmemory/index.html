记录灵感，
积累记忆，
展开长文。

灵感散落在备忘录，收藏沉睡在书签栏，选题停在脑海里。XMemory 把三者放进同一个安静的写作空间：按日记灵感，自动沉淀 X 书签，再把一个想法写成完整的文章。

01 / 工作区

三个工作区，串起一条写作链路。

灵感按日记录，记忆自动沉淀，选题展开成文。全局搜索和双向链接把它们连在一起，想写的时候素材就在手边。

灵感

每天留下一点想法

周/月日历，输入标题按 Enter 就记下。一条灵感就是一条待办，用过就勾选划线，可拖动排序或移到其他日期。

记忆

从收藏到积累

X 书签每小时增量采集，保留正文、原文链接、原图和长文结构，沉淀成按发布时间排列、可检索的资料库。

选题

把想法写成长文

在同一篇文档里写大纲和正文。写完勾选划线，未完成的始终排在前面，随时续写或撤销完成。

02 / 书签采集

收藏过的推文，不再沉睡。

开启自动采集后，XMemory 每小时增量抓取一次 X 书签，已采集的自动跳过。长文保留标题、列表、引用、代码块和原位配图，短链接还原为真实地址。

  • 每天最多新增 200 条，每轮有上限，自带熔断保护
  • 登录失效、限流时跳过并说明原因，不弹窗打扰
  • 不完整的记忆可手动或自动补采，保留你的笔记
  • 默认关闭，使用本机 Chrome 的独立 Profile

03 / 长文选题

大纲和正文，写在同一篇文档里。

每个选题是一条待办，点开就能写。所见即所得的 Markdown 编辑器，富文本与源码一键切换。

  • 表格、链接、双向链接与笔记摘要嵌入
  • 粘贴图片直接存到本地，双击放大
  • 自动保存，外部编辑 Markdown 后可回读
  • 导出当前笔记及其引用的本地图片

04 / 搜索与主题

找得到，也看得舒服。

全局搜索覆盖灵感、记忆、选题和候选稿，命中关键词黄色高亮，点击结果直接定位到正文。和纸主题提供亮、暗两版，正文与标题使用随应用打包的思源宋体。

05 / 数据与隐私

没有账号，数据始终在你手里。

本地优先
正文是标准 Markdown 文件，图片存在本地，可以用任何编辑器打开或整体迁移。删除的内容先进回收站。
私有同步
需要多台设备时，用你自己的 GitHub 私有仓库双向同步：启动时和每 10 分钟一次，冲突时保留双方，可手动合并。
凭据
GitHub Token 用系统能力在本机加密保存，不写入资料库，也不参与同步。
无云端
不内置任何云端服务，不收集遥测。搜索索引可随时从 Markdown 完整重建，删掉也不丢内容。

06 / 安装

下载即用。

支持 Windows 10/11 x64。X 书签采集需要本机安装正式版 Google Chrome；不用采集也可以单独记录灵感和写作。

  1. 下载从 GitHub Releases 下载安装版 .exe，或免安装版 .zip。
  2. 运行安装包暂未签名，首次运行若出现 SmartScreen 提示，选择「仍要运行」。
  3. 开启采集可选。在设置中开启自动采集，首次在弹出的 Chrome 中登录 X。
  4. 配置同步可选。填入 GitHub 私有仓库和 Token，多台电脑共用同一份资料库。
