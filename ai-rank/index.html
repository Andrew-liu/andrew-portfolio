Interactive tool · Web · 中 / EN

拖一拖，
排出你的 AI 榜单。

把常用的大模型和编程 Agent 拖进不同档位，写上你的名字，一键导出一张适合发到社交平台的 PNG 榜单图。

开始排榜 ↗ 查看源码 ↗
  • 2份榜单：模型与 Agent
  • 5个档位
  • 0后端与账号

01 / 功能

打开就能用，排完就能发。

不用注册，不用安装。所有操作都在一个页面里完成。

DRAG

拖拽分级

把卡片拖进档位，同一档内也能拖动换位，周围卡片会平滑让位。

MODELS / AGENTS

两份榜单

AI 模型和 AI Agent 各一份，切换互不影响。候选池按厂商筛选。

CUSTOM

自定义条目

新模型刚发布、列表里还没有？自己加一张卡片，选好厂商就行。

PNG

导出与复制

下载 PNG 或直接复制到剪贴板，图上带着你的名字和 X 账号。

02 / 分享

一张图，说清你的偏好。

榜单本来就是主观的。My AI Rank 只负责把你的判断排得好看，导出的图片和页面上看到的一模一样。

  • “夯 / 顶级 / 人上人 / NPC / 拉完了”五档，中英文界面一键切换
  • 厂商图标自动匹配，几十个主流模型开箱即用
  • 导出时自动隐藏编辑按钮，只留下榜单本身

03 / 数据与隐私

榜单只留在你的浏览器里。

本地保存
榜单、自定义条目、名字和账号信息都存在浏览器 localStorage 中，刷新页面也不会丢。
不上传
没有后端服务，也没有账号系统，任何内容都不会发到服务器。
纯静态
原生 HTML、CSS 和 JavaScript，依赖随站点一起分发，国内网络也能正常加载。
主观声明
预设条目与分级仅为个人整理，不构成对任何模型或厂商的评价。
