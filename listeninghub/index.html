英语学习 · Web / PWA · 可离线

听懂，
而不只是听过。

基于 VOA Special English 的沉浸式听力练习。逐句精听、中英对照、点词即查，再把生词送进间隔复习，让每一次听力都留下点什么。

开始练习 ↗ 查看源码 ↗
  • 100篇精选材料
  • 20个学习主题
  • 2.6万词库词汇

01 / 逐句精听

一句一句，听到真正听懂。

每篇材料拆成十几句，可以单句循环，也可以整篇连播。正在读的句子会高亮，英文下方是中文翻译，随时显示或隐藏。

  • 点击任意单词查词典，一键收进生词本
  • 听写模式：听完默写，自动和原文比对
  • 跟读录音：录下自己的发音，和原句对照

02 / 学习闭环

听、记、复习，放在同一个地方。

听力里遇到的生词，会在合适的时间再回来找你。

VOCAB

智能生词本

收藏的单词按 SM-2 间隔复习算法排期，忘得越快，出现得越勤。

WORDS

背单词

初高中、四六级、考研、托福、SAT 七大词库，卡片式记忆，释义可隐藏自测。

SPELLING

拼写模式

拼错次数自动换算成复习评分，错三次以上的词会自动进入生词本。

PROGRESS

打卡与勋章

记录打卡天数、连续学习和已听句数，15 枚成就勋章覆盖听力和词汇。

03 / 架构

没有账号，没有服务器。

一个纯静态单页应用，打开就能用，装到桌面后断网也能练。

本地存储
学习进度、生词本、成就全部保存在本机浏览器里，不需要登录。
离线可用
支持 PWA 安装，Service Worker 缓存后无网也能继续练习。
零依赖
Vue 3 加 Tailwind CSS，不需要构建步骤，词库转成静态 JSON 分片按需加载。
三套主题
明亮、复古、暗黑三种配色，长时间阅读更护眼。

04 / 开始使用

今天先听一篇，五分钟就够。

直接在浏览器里打开，手机上也能用。
