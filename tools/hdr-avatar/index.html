导出格式与检查说明

sRGB 解码 → 线性 BT.2020 合成 → ST 2084 PQ；遮罩和预乘人物分别用 Hamming 重采样。背景固定色，其余 254 色采用中值切分、k-means 与 Floyd–Steinberg 抖动，并抑制人物上的量化亮点。

PNG 块顺序：IHDR → cICP（9,16,0,1）→ iCCP → PLTE → IDAT → IEND。ICC 由发布构建中的 macOS 通过 CGColorSpace.itur_2100_PQ 导出。屏幕显示亮度受设备峰值与系统映射影响。
