在 X 的信息流里，为每条推文标出实时流速和 AI 腔指数，为每个账号标出粉丝量级与质量。另附视频下载和一套克制、可控的互关清理工具。

01 / 功能

四个功能，各自独立开关。

只想看流速，就只开流速。所有改动即时生效，不用刷新页面。

🚀 10.3万/h

推文流速

浏览量除以发布至今的小时数。1k、5k、1w 起依次进入三档，档位越高越亮，爆款带光晕，滑动时一眼就能抓住。

AI 94%

AI 文本检测

中英文两套规则，识别套话开场、总结收尾、万能夸夸回复和排版套路，给出 0 到 100 的 AI 腔指数。完全在本地计算。

大V · 高互动

账号标签

粉丝量级、关注/粉丝比，以及互关、未回关、大V、新号、老号、高互动、低活跃、疑似互粉号八种质量标签。

↓ 1080p

视频下载

时间线操作栏多一个下载按钮，或在弹窗粘贴推文链接，按清晰度保存 mp4。仅限个人保存与学习使用。

02 / 细节

悬停一下，数据全摊开。

悬停任意标签，弹出账号与推文的详细数据卡：粉丝、关注、比值、注册时长，浏览、赞、转、评、藏和爆款分，以及 AI 检测命中的具体规则。

  • 自动适配 X 的浅色、暗蓝、纯黑三种背景
  • 中文与英文界面，英文下数字用 K / M / B
  • 标签可跟在名字后，也可单独一行，不让时间线跳动

03 / 主题

八套主题，不只是换个颜色。

热度条、信号灯、徽章、贴纸、终端、霓虹、原生文字、极光。形状、字体与排版各不相同，流速、AI 检测、账号标签和悬停卡共用同一套。

04 / 互关清理

清理未回关，但节奏由你掌控。

只在自己的「正在关注」页出现。筛出未回关账号，勾选后批量取关，点击的是 X 自带的按钮。

  • 宁漏勿误：无法确认关系的账号不会被选中
  • 间隔 1 到 5 秒可选，带随机抖动
  • 每小时最多 50 人，跨刷新和多标签页共享额度
  • 执行前二次确认，过程中随时可停

05 / 设置

一个弹窗，五个页签。

标签、主题、下载、互关清理、通用。顶部实时预览，改完立刻看到效果。

06 / 隐私

不让你的数据离开浏览器。

网络请求
标签只读 X 页面已加载的 GraphQL 响应。唯一例外是视频下载：页面里没有数据时，请求一次 X 官方嵌入接口，不带 Cookie。
AI 检测
正文只在当前页面用本地规则打分，不上传、不调用任何模型接口。
存储
只保存你的设置和最近一小时的取关时间戳，不记录浏览历史。
第三方
无统计、无遥测、无远程配置、无 CDN 依赖。代码不压缩，可逐行审阅。

07 / 安装

三分钟装好。

暂未上架 Chrome 网上应用店，请以开发者模式加载。Edge、Brave、Arc 等 Chromium 浏览器通常也可用。

  1. 下载从 GitHub Releases 下载 zip 并解压。
  2. 开启开发者模式打开 chrome://extensions，打开右上角的开发者模式。
  3. 加载扩展点击「加载已解压的扩展程序」，选择包含 manifest.json 的目录。
  4. 打开 X刷新 x.com，标签就会出现在推文头部。
