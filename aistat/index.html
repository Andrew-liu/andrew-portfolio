一眼掌握。

01 / 功能

为长时间写代码的人准备的三件事。

适合每天开着 Claude Code、Codex 跑任务的 macOS 开发者。

AI USAGE

AI 预算

Codex 额度、Token 用量和成本概览；有本地数据源时同时显示 Claude 额度。刷新失败时沿用上一次成功的结果，不会突然变空白。

SYSTEM

系统状态

CPU、内存、磁盘、电池四个环形指标，外加磁盘读写速度，点开可查看详情。

KEEP AWAKE

防睡眠

15 分钟到永久七档可选，同时阻止空闲睡眠和屏幕变暗。菜单栏图标会跟着状态变化。

02 / 数据来源

数据读得到，就读最准的那一份。

每个 Provider 都有一条按顺序降级的读取链。窗口是 30 天就显示 30d，不会硬套成 5h 或 Week。

  • Codex：OAuth usage API → CLI RPC → 本地会话日志 → 上次缓存
  • Claude：OAuth 凭据文件 → Claude Code CLI → 上次缓存
  • 默认不碰 Keychain，避免弹出系统密码提示
  • 按指标模块化，方便以后接入更多 Provider
系统指标
在本机直接读取。
Token 与成本
扫描本地 Codex 和 Claude Code 日志。
额度
请求 Provider 官方 usage 接口，这是唯一的网络访问。
后端
没有。数据不会上传到任何自定义服务器。

03 / 安装

下载、拖入、打开。

需要 macOS 14 或更新版本。想自己构建的话，用 Xcode 打开工程即可运行。

  1. 下载从 GitHub Releases 下载最新的 .dmg。
  2. 安装把 AIStat.app 拖进“应用程序”文件夹。
  3. 首次打开右键点击应用，选择“打开”，绕过 Gatekeeper 提示。

DMG 目前还没有经过 Apple 公证，所以首次启动需要右键打开。之后正常双击即可。
