01 / 功能

不是又一个新闻流，而是一张信号表。

同一件事被十家媒体转载，在这里只出现一次，后面挂着全部来源。你可以先看结论，再决定点开哪一篇原文。

EVENTS

同事件合并

把重复报道聚成一个事件，标出独立来源数，展开即可看到每一条原始报道。

RANKING

重要性排序

按来源等级、独立来源数和时效打分，热榜与最新两种视角，排序本身不依赖大模型。

FILTER

可解释的 AI 过滤

用可读的规则判断内容与 AI 的相关度，误伤和漏网都能追溯到具体规则。

CHINESE

中文优先

生成中文标题、短摘要和推荐理由，英文原标题保留在下方，方便对照。

02 / 阅读体验

像读一份报纸头版。

按模型研究、开发工具与 Agent、开源与 GitHub、芯片与机器人、融资与财报、安全与产品六个赛道分栏，每个赛道都能切换全部、热门和最新。

  • 每条都标出来源等级、发布时间和独立来源数
  • 热度分数可视化，一眼看出谁在升温
  • 多套阅读主题，长时间看也不累
  • 只展示标题、摘要和原文链接，不搬运全文

03 / 工作原理

一条每小时运行一次的管线。

Python 管线跑在 GitHub Actions 上，产出静态 JSON，再由纯静态前端读取。没有服务器，也没有数据库。

  1. 采集官方博客、AI 媒体、RSS/OPML、Hacker News、GitHub
  2. 标准化统一字段、清洗标题与时间
  3. 过滤增强AI 相关性评分，生成中文标题与摘要
  4. 聚类排序去重、合并同一事件、计算重要性
  5. 门禁发布测试、脱敏、质量检查通过后才部署

04 / 可信度

把“为什么出现在这里”讲清楚。

保留信源
每个事件都附带全部原始链接和来源名称，结论可以回到原文核对。
质量门禁
候选数据先过测试、脱敏和质量门禁，数据过期或异常时不会发布。
来源健康
站内展示各信源的健康状态、AI 内容占比和采集异常，问题不会被悄悄藏起来。
版权边界
第三方内容版权归原作者，站点只展示必要摘要与原文链接。
